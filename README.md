# Nick Berghane — live portfolio

A lightweight static portfolio with a clear professional front door and separate paths into working tools and the experimental lab.

## Current structure

- `index.html` — portfolio homepage, selected work, services, and project brief flow
- `chronosaudit.html` — local SHA-256 evidence-manifest tool using Web Crypto and IndexedDB
- `archive/workspace-v1.html` — preserved copy of the previous all-in-one interactive workspace

## Working rule

A control either performs the operation it describes or the interface labels it as a prototype. Experimental work lives behind the Explore layer rather than crowding the primary professional path.
