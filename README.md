# ChronosAudit

ChronosAudit turns a messy local document corpus into an inspectable, provenance-preserving historical timeline where every event can be traced back to the original evidence.

This branch is the temporary staging home for the Phase 1 public product demonstration while the dedicated `coldysquares/chronosaudit` repository is created. It is intentionally isolated from `live-portfolio/main` and is not intended to merge into the portfolio.

## Current checkpoint

- Real bundled synthetic investigation: **The Harbor Permit Revision**
- Timeline → assertion → exact source lines → original-file record → provenance
- Explicit, relative, metadata, conflict, and unresolved evidence remain distinct
- Three surfaced contradictions and one metadata-sequence anomaly
- Search, filters, JSON export, printable report, Method page, and Security Boundary page
- No visitor file upload and no model call in the public demo

## Product boundary

The public site demonstrates the method with checked-in fictional evidence. The canonical working product is a local desktop instrument for real private corpora.

Before meaningful changes, review `docs/PRODUCT_CANON.md` and `docs/NEXT_BUILD_PLAN.md`.
