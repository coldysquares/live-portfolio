# ChronosAudit Product Canon

## Definition

ChronosAudit turns a messy local document corpus into an inspectable, provenance-preserving historical timeline where every event can be traced back to the original evidence.

## Audience

Investigative journalists, researchers, legal teams, historians, FOIA investigators, nonprofits, corporate investigators, and anyone working with document collections where when something happened, where a claim came from, and how information changed over time matter as much as the content itself.

## Core workflow

1. Select a local corpus.
2. Preserve and inventory originals.
3. Extract metadata and dated claims.
4. Reconstruct events and changes over time.
5. Surface contradictions and anomalies.
6. Inspect every result against the evidence beneath it.
7. Export portable reports, manifests, and processing receipts.

## Authority chain

`timeline event -> extracted claim -> exact source passage -> original file -> hash/provenance record`

A timeline event is a derived projection. It is never the underlying authority.

## Temporal evidence types

- filesystem timestamp
- embedded metadata
- email header
- explicit text
- relative temporal reference
- model inference
- conflicting date
- unresolved date

Observation, normalization, inference, conflict, and uncertainty remain visibly and structurally separate.

## Hard product boundaries

- Not a generic document chatbot.
- Not a hash utility.
- Not a public private-file upload demo.
- Not a system that silently reconciles contradictions.
- Not a system that mutates originals or converts model inference into observed fact.
- Not a generic SaaS dashboard.

## Public site

The public site explains the product and demonstrates the event-to-evidence relationship with a checked-in synthetic corpus. It does not request private files.

## Canonical application

The canonical application is a local desktop instrument. Real investigation corpora stay on the user’s device by default. Optional remote model operations must be bounded, disclosed, and receipted.
